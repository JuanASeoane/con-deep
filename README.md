# Detectores Rn - Toma de datos

App para registrar detectores de radon, organizados por centros, con generacion de PDF.

## Como compilar con GitHub Actions

1. Sube esta carpeta a un repositorio de GitHub
2. GitHub automaticamente compilara la APK
3. Descarga la APK de la seccion "Actions"

## Como probar localmente

```bash
pip install kivy plyer pillow reportlab
python main.py
```
